
== Проект: todoList_task_pwa==

=== Описание ===
Проект **todoList_task** — это веб-приложение для управления задачами, разработанное с использованием современных технологий. Приложение позволяет пользователям создавать, редактировать и удалять задачи, а также организовывать их по категориям и приоритетам.

=== Используемые технологии ===
- **React** — библиотека для построения пользовательских интерфейсов.
- **Vite** — современный сборщик проектов, обеспечивающий быструю разработку и сборку.
- **Ant Design** — UI-библиотека для создания красивых и удобных интерфейсов.
- **TypeScript** — язык программирования, расширяющий JavaScript статической типизацией.
- **Redux Toolkit** — инструмент для управления состоянием приложения.
- **CSS Modules** — методология для написания модульных стилей, предотвращающая конфликты имен классов.
- **Docker** — платформа для контейнеризации приложений, упрощающая развертывание и управление зависимостями.

=== Установка и запуск ===
1. Клонируйте репозиторий:
git clone https://github.com/ваш_репозиторий/todoList_task.git cd todoList_task

2. Установите зависимости:
npm install

3. Запустите приложение:
npm run dev

4. Откройте браузер и перейдите по адресу `http://localhost:5173`.

=== Контейнеризация ===
Для запуска приложения в Docker выполните следующие шаги:
1. Соберите образ:
docker build -t todoList_task .

2. Запустите контейнер:
docker run -p 5173:5173 todoList_task
